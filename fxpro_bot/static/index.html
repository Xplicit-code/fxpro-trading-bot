Connect locally. Start explicitly.

Real broker quotes and orders require this dashboard running on Windows alongside the FxPro MT5 terminal. The cloud preview supports paper trading and shows the connection form without collecting credentials.

  1. Install this project and the MT5 extra on Windows.
  2. Open the FxPro terminal and enable algorithmic trading and the external Python API.
  3. Start the dashboard, then enter your login, password, exact server and instrument in the Overview connection form.
  4. Connect a demo account first. Press Start Trading when ready. Press Stop Trading to disable automatic bot orders.
